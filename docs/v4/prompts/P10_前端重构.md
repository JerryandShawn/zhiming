## 背景（为什么重做）

旧前端 `static/app.js`（181KB / 2174 行，单行常超 1000 字符）：92 处 `innerHTML` 拼接、64 处内联 `onclick`、全局变量状态；三套样式互相覆盖（深色 `base.css` + 60 个 `!important` 的 `paper.css` + Tailwind 预检）；8–11px 小字 92 处、对比度不达标；没有 webfont（Windows 回退宋体）；没有暗色；每页 100–130px 装饰标题；假打字光标；"本轮依据"面板永远显示 0；旧"应验率"页面与产品定位冲突；pending 记忆在 App 里无法确认。用户的评价是"审美很差"，并要求设计**尽可能具体**。

**用户已确认的视觉方向：新中式·宣纸、墨、朱砂。** 浅色：宣纸 `#F6F1E7`、墨 `#1F1B16`、朱砂 `#B23A2E`、古金 `#8A6D3B`；标题用思源宋体/霞鹜文楷，正文用思源黑体；暗色"夜墨" `#14110E` 配淡金。使用场景：手机端以**飞书内嵌**为主，同时有手机浏览器与桌面浏览器。

## 技术栈与结构

- `web/`：Vite + React 18 + TypeScript（strict）+ Tailwind CSS v4（主题变量来自 08 §2 的 token）+ Radix UI primitives（以 shadcn/ui 方式把组件源码放进 `web/src/components/ui/`）+ lucide-react（描边 1.5）+ Motion（`motion/react`）+ TanStack Query + Zustand（少量 UI 状态）+ DOMPurify + marked。
- 构建到 `static/dist/`（带内容哈希），FastAPI `GET /` 返回 `static/dist/index.html`；旧 `static/index.html` 与 `app.js` 在 P11 退役前通过 `/legacy` 保留可访问。
- 路由：hash 路由（保持旧深链可用）：
  | 新路由 | 页面 | 旧路由重定向 |
  | --- | --- | --- |
  | `#/today` | 今日 | `#/`（默认） |
  | `#/chat` | 对话 | `#/chat` |
  | `#/chart` | 命盘（`?tab=bazi|ziwei|astro&date=`） | `#/chart` |
  | `#/tarot` | 塔罗（`?draw=`） | `#/tarot?draw=` |
  | `#/cases` | 事项 | `#/cases` |
  | `#/me` | 关于我（画像、记忆、重要的人、时间线、个人符号词典、待确认） | `#/memory`、`#/timeline`、`#/graph`、`#/dict` → 对应分区 |
  | `#/settings` | 设置（`/reports` 报告与提醒、`/quiet` 免打扰、`/models` 模型、`/devices` 设备与登录、`/privacy` 无痕与数据） | `#/reportsettings` → `#/settings/reports` |
  | `#/reports` | 报告归档（`?date=`） | `#/reports?date=` |
- 字体：自托管，按 unicode-range 切片（例如使用 `lxgw-wenkai-webfont` 的切片方式，或用 `cn-font-split` 对思源宋体/思源黑体生成切片），放 `web/public/fonts/`；`font-display: swap`；首屏只预加载正文字体的常用切片。**零境外 CDN**；飞书 JS-SDK 仅在飞书容器内动态加载（P9）。
- 安全：生产 CSP `default-src 'self'; img-src 'self' data: blob:; style-src 'self'; script-src 'self'; connect-src 'self'`（飞书页面额外放行 SDK 域名）；无内联脚本与内联事件；Markdown 一律经 DOMPurify（禁止 img/iframe/form/style，与旧行为一致）。

## 里程碑

- **M1 设计系统**：token（CSS 变量，浅/暗）、字体、间距、组件库（08 §5 列出的全部组件及其所有状态），Storybook 或一个 `#/__design` 内部页展示全部组件；Playwright 截图。
- **M2 静态页面**：七个页面用假数据（合成）实现，桌面 1440 与手机 390 两种布局对照 08 §6 的线框与 08b 参考稿逐区还原；截图对比报告。
- **M3 对话接入**：`POST /api/chat` + SSE v2（`Last-Event-ID` 续传）；渲染 `text_delta`、`status`、`tool_call/result`（工具状态行）、`memory_receipt`（回执条 + 撤销）、`ask_user`（提问卡）、`present_options`（决策卡）、`text_reset`（修订替换 + "已修订"标记）、`final`；停止按钮；断线恢复；历史分页（含飞书消息徽标）；图片上传（≤4 张、≤5MB、JPEG/PNG/WebP）；无痕开关。
- **M4 其他页面接入**：今日（此刻信息、今日流日、安排与跟进、最近对话入口）、命盘（三盘 + 日期切换 + 依据可点）、塔罗（完整抽牌流程，固定牌不变量）、事项、关于我（画像条目编辑、记忆列表与来源/撤销/删除、待确认 proposal、重要的人、时间线）、设置（报告计划、免打扰与每日上限、晨报时间、模型选择只读展示或切换、设备会话吊销、无痕说明）。
- **M5 打磨**：动效（08 §7，仅 3 处有意动效）、暗色、可访问性、性能（首屏 JS ≤ 200KB gzip，LCP < 2.5s 于模拟 4G 手机）、飞书内嵌适配（安全区、键盘弹起、返回手势）。

## 必须保留的行为契约（来自旧测试，逐条写成新测试）

1. 所有写操作带稳定 `request_id`（塔罗另有 `idempotency_key`）：模糊失败（网络断、超时）后用**相同 ID** 重试；确认成功后再次操作生成新 ID；ID 在 `sessionStorage` 中跨刷新保留（对应旧 `app.js:89-96, 1810-1815`）。
2. 所有修改带 `expected_revision`；409 时**保留用户草稿**、禁用保存、提示"内容已在别处更新，刷新后核对"，不得盲目重提交。
3. 运行生命周期：查询 `/api/runs/{id}` → 成功则渲染；运行中则续接事件流；失败则 `POST /api/runs/{id}/retry`（同一运行）；用户可明确"开始新一轮"；取消调用 `/api/runs/{id}/cancel`。
4. 资料确认：必须勾选同意；精度为"未知"时禁用时间输入；"大约"要求填写不确定分钟数；成功提示只来自回执。
5. 记忆：保存/修改/删除提示**只来自程序回执**；修改结构化字段需确认勾选且新值出现在文本中；删除区分"只删这条"与"删除整段来源"。
6. 塔罗：服务端抽牌；揭牌前牌背不透明（`/static/tarot/back.svg`）；揭牌、点选、取消、手动修正幂等；解释失败绝不重抽；多解释版本可查看；A/B 选项冻结显示；选牌支持方向键移动焦点；"全部揭开"在减少动效模式下无动画。
7. 报告设置：PATCH 载荷键严格为 `kind, request_id, expected_revision, enabled, time` 加 `weekday` 或 `day`；北京时间说明与"提前 15 分钟准备"文案；回执校验；409 保留草稿。
8. 深链：上表全部旧路由可用。
9. 可访问性：模态/抽屉/搜索关闭后焦点回到触发元素；焦点陷阱；所有交互可键盘操作；`prefers-reduced-motion` 生效；移动端键盘弹起时输入框可见。
10. 登录：`X-Token` 输入框登录（桌面）；cookie 会话（飞书免登，P9）；401 统一弹出登录。
11. 私有字段（如塔罗私有牌序、出生资料原值在非资料页）绝不渲染。

## 测试

- 单元：Vitest + Testing Library（组件、hooks、SSE 客户端、幂等 ID 管理、409 处理）。
- 端到端：Playwright，后端用 FastAPI + 隔离 PG + `ScriptedProvider`；覆盖上面 11 条契约与 M3 的全部事件类型。
- 视觉：Playwright 在 **375×812、390×844（飞书常见）、768×1024、1440×900** 四种视口、浅色/暗色两种主题下，对七个页面各截图；与 08b 参考稿截图并排放在 `docs/v4/evidence/P10/compare/`，并写一份逐页自评（对照 08 §10 的截图验收清单逐项打勾）。

- 旧 JSDOM 测试（`tests/*.cjs`）在 P11 退役；本阶段保持旧前端在 `/legacy` 可用，旧测试继续跑。
