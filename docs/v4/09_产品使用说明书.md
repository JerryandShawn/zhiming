# 09 · 明镜台 v4 使用说明书（给你自己用）

> 这是改造完成后的使用方式。各项功能按阶段陆续上线（见 `00_先读我` 的上线批次表），没上线的部分会照旧。
> Codex 写界面文案时也会参考本文的语气。

---

## 一、明镜是谁

明镜是一位懂命理的老朋友：
- **记得你的事**：你随口提到的近况、计划、在意的人和事，它会记下来，下次自然接上。
- **知道今天是什么日子**：几号、星期几、农历、节气、今天放不放假、是不是调休上班、下个假期还有多久。
- **会主动关心你**：不懂就问（一次只问一个），约好的事到时候会来问问结果，每天早上给你一份晨报。
- **懂行**：八字、紫微斗数、西洋星盘、塔罗，都能有依据地讲，并告诉你依据和流派。
- **说实话、有分寸**：不吓唬你，不说"注定"，健康、法律、投资问题会建议你找专业的人。

## 二、第一次见面（约 10 分钟，可以随时暂停）

第一次打开时，明镜会先跟你打个招呼，然后慢慢认识你：
1. 问你希望怎么被称呼，也问你想怎么叫它（默认"明镜"）。
2. 请你补充出生资料：日期、时间（不确定也没关系，选"大概"或"不知道"）、出生地。这些会弹出一张**确认卡**，你核对后点确认才会保存。
3. 聊聊你最近过得怎么样、最在意的一两件事。
4. 问你喜欢它直说还是委婉、命理术语多一点还是少一点。
5. 问你能不能接受它每天早上 7 点发晨报，约好的事到时候来问你；晚上 10 点到早上 8 点不打扰。
6. 最后，它会说说"目前了解到的你"，再送你一个小小的见面礼：你的日主和性格底色。

想先问别的事？直接问。它会先回答你，之后再找机会继续认识你。说"先到这"就会暂停，下次再接着来。

## 三、在飞书里用（手机上的主要方式）

- **直接发消息**：文字、图片都可以。连着发几条，它会等你说完再一起回复。
- **回答是一个字一个字出来的**：卡片会实时更新，最后定稿。
- **它问你问题时**：卡片上会有几个选项按钮，点一下就行；也可以直接打字回答。
- **"记下了"提示**：它记住了什么，卡片底部会写出来，旁边有**撤销**按钮。
- **比较私人的事**（健康、别人的隐私、具体金额等）：它会先问"要不要我记住？"，你可以点"记住""不用"或"以后这类都记"。
- **打开完整页面**：点卡片上的"在明镜台打开"，会在飞书里直接打开网页版，不用输口令（需要先在飞书后台开通，见 `00_先读我`）。
- **主动消息**：每天早上的晨报；你提过的事（比如"周三面试"）到时候它会来问问；每天最多 2 条（不算晨报），晚上 10 点到早上 8 点不打扰。

## 四、网页版（手机浏览器和电脑都能用）

底部（手机）或左侧（电脑）有这几个页面：

| 页面 | 用来做什么 |
| --- | --- |
| **今日** | 今天的日期、农历、节气、放不放假；今天和这几天你的安排；今日流日对你的一句提示；黄历；进行中的事 |
| **对话** | 和明镜聊天。飞书上聊过的内容也在这里，并标着"飞书"。电脑上右侧能看到"这轮用到了哪些记忆和盘面" |
| **命盘** | 八字、紫微、星盘。可以换日期看流年、流月、流日。点任何一个字都有白话解释和"问问明镜"按钮 |
| **塔罗** | 提问 → 选牌 → 揭牌 → 解读。牌一旦抽出就固定了，重新解读不会换牌；想重抽就开新的一次 |
| **事项** | 你正在跟进的事（比如"跳槽"），能看到目标、进展、相关的对话和塔罗 |
| **关于我** | "明镜眼中的你"：它对你的了解、它记住的每一件事（附原话和日期）、待你确认的、重要的人、时间线 |
| **设置** | 晨报和周期报告的时间、主动联系的开关与上限、免打扰时段、主题（宣纸/夜墨）、登录设备 |

## 五、记忆：它记什么、怎么改、怎么删

- **默认会记**：你的近况、计划、喜好、习惯、目标、顾虑、重要的人和事。每次都会提示"记下了：……"，随时可以撤销。
- **会先问你**：身体和心理健康、别人的隐私、具体的钱数和债务、宗教政治、官司等。
- **不会记**：
  - 你说"这个别记""忘了吧"的内容；
  - **无痕模式**下的所有对话。在网页右上角打开无痕，或者直接说"开个无痕"。
- **它的推测**（比如"你好像对工作有点倦怠"）会标成"推测"，不会说成"你说过"。
- **查看和修改**：打开"关于我"，每条记忆都能看到来自哪句话、哪天说的；可以修改、停用、删除。删除时可以选"只删这条"或"删除整段原话"（后者会把由它整理出的画像、摘要也一起清掉）。
- **旧版记忆**：改造后，以前存过但"卡住"的记忆会恢复回来。你会收到一条"从旧版迁入 N 条 [查看/撤销]"的提示，不想要的可以一键撤回。
- 已经发到飞书的消息没办法撤回，这一点请知悉。

## 六、命理怎么讲

- 盘面是程序算出来的，明镜不会凭印象说你的八字。
- 它会讲旺衰、格局、喜用神、大运流年、紫微四化、星盘行运等；每个判断都会附上**依据**（点小注脚能看到是哪个盘面数据），并说明是哪种流派的看法。流派之间有分歧时，会把几种说法都告诉你。
- 讲的是趋势和条件，不是定数；最后一定会落到"你现在能做什么"。
- 出生时间不准时，它会告诉你哪些结论受影响。
- 想听更深的分析，就说"详细看看"或"深入分析一下"：它会请八字、紫微、星盘各自的"专家"分别看，再综合给你。

## 七、提醒与晨报

- "明天早上 8 点提醒我交材料"：它会按时提醒。你明确说的时间不受免打扰限制。
- "别再提醒面试的事了""以后别问我感情的事"：它会关掉对应的跟进。
- 晨报和周报、月报、季报的时间在"设置 → 晨报与周期报告"里改。

## 八、换模型

- 明镜默认用 Kimi，备用 DeepSeek、通义千问、智谱 GLM。主模型不可用时会自动换备用模型，你不需要做什么。
- 回答会由另一个"独立的明镜"做一次复核：用的是同一个模型，但它看不到原来的思考过程，只对照事实（日期、记忆回执等）挑错。修正过的回答会标"已修订"。
- 想换主模型：在"设置 → 模型"里切换（或者告诉 Codex 改 `config/models.yaml`）。

## 九、常见问题

- **它说错了日期/节假日怎么办？** 直接纠正它，并把截图发给我（Claude）——这是评测里的重点项目，会排查原因。
- **2027 年的放假安排？** 国务院一般在 11 月公布；公布之前它会如实说"还没公布"，公布后数据会更新。
- **它问太多了？** 说"先别问了"，它会安静 7 天，除非你主动聊。
- **它太啰嗦/太简短？** 告诉它"以后说短点"或"多讲点细节"，它会记住你的偏好。
- **我的数据在哪？** 都在你自己的服务器数据库里。模型调用时，相关内容会发给你选择的模型服务商；不会发给其他任何追踪或分析服务。
