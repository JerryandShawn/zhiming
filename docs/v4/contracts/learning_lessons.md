# 命理研习20课 v1：静态合成教学草稿

对应33号第二节第5项。数据入口为 `mingjing_core/knowledge/p8_learning_lessons/curriculum_v1.json`，
单课在同目录 `lessons/lesson-01.json` 至 `lesson-20.json`。Schema 为
`docs/v4/contracts/learning_lessons.schema.json`，同时校验课程目录和单课；版本分别是
`p8-learning-curriculum-v1`、`p8-learning-lesson-v1`。

这是前端可读取的数据契约，未新增工具、HTTP接口或教学进度服务。20课和40道题的正文已经起草，
状态固定 `draft_for_review`，不把结构验证称作20课专业验收。未接前端、Agent或主线账本。

## 输入与输出

读取方先取得目录，再按 `lesson_id` 对应的 `path` 加载单课JSON。
路径限本仓库相对路径，拒绝绝对路径、`..` 越界和外部引用；读取不执行来源URL或附带代码。
没有当前用户出生信息输入，也不从课程静态样例推断当前用户盘面。

| 数据 | 内容 |
| --- | --- |
| curriculum | 20项目录、40题数量、3个合成case、6份样例SHA、来源版本/SHA、20条精确观察依据和限制 |
| lesson | 目标、前置课、两段不同正文、实际阿远例子、两题、出处ID、流派差异、待核 |
| cases | 每个case自己的system/scope、chart路径与SHA、learning路径与SHA、真实卡片ID |
| evidence | case_id、已有c短号、相对该c所指JSON值的Pointer、expected、原有r短号、依据角色 |
| quiz | 题干、3个不同选项、答案ID、解释、依据种类与期望值 |

所有案例都是已经交付的合成人物阿远，不另填真实出生资料。三套信封的operation不同，
`ayuan-bazi:c3` 与 `ayuan-ziwei:c3` 不是同一依据。前端显示短号时必须同时保留该例的case/operation上下文，
不能把不同课、不同case的c1或r1合成一份当前用户依据账本。

## 依据与题目判定

`relative_path` 相对原信封已有c引用解析出的值。例如本例八字c3指向整个实际主盘，
`/p8/ten_gods/day_master` 得到丁；这是原有宽依据内读取字段，没有创建新的细粒度c。
JSON Pointer须严格解码 `~0/~1`，数组只接受ASCII规范非负索引；`-1`、`01`、越界、缺键均拒绝。

`role=primary` 的c必须就是该case的实际 `view.primary` 引用，诊断盘不能替换；
`basis` 只用于实际登记的时间坐标；`rule_input` 必须同时复用至少一个真实r，且c在其
`evidence_aliases` 中、原生命中 `met=true`，规则版本/分支与原信封一致。
目录不另存或修改原生规则，也不造“本课命中”。

题目分三种：

- `chart_observation`：答案值与实际c/Pointer解析值、目录expected三者严格相等，类型也相同。
- `matched_rule`：除上述值绑定外，还核真实r及其输入c关联。本课有r8正印透干、r1伤官牵制筛选、r10交界输入。
- `concept`：只引用已注册source_id，答案是作者编写的概念区分，不声称阿远已计算另一种出生、流派或未实现技术。

选项的 `option_id` 仅用于前端选择；取正确选项的 `value` 和basis.expected严格比较，不靠文字猜答案。
所有错误选项的值须与正确值不同，不把布尔false视为数字0；改变选项顺序不改变答案ID/依据。
概念题不能添加c/r来伪装实盘命中。未通过的格局候选只引用真实c值false，绝不补r。

`worked_examples.learning_point_ids` 是原学习样例中相关卡片的伴读链接，允许为空。
例如时间课链接真实交界卡、规则课链接对应条件卡；链接不表示学习卡覆盖整课每句话。
实际chart信封仍是观察值依据，learning样例是已有纯规则表达，不替代盘面。

调用方若读不到固定样例、SHA不符、case缺失、Pointer无效、c/r不能解析、题目类型与依据不一致，
应显示“样例依据已更新，待重新复核”，不能回退为作者记忆中的旧答案。
主线重新计算样例后，须重新校验并更新该目录SHA；不能只重写SHA来掩盖观察值变化。

## 出处、流派与验收边界

每课source_id解析到现有 `knowledge/p8_glossary/sources_v1.json` 的具名来源，目录固定版本与SHA。
源码支持项目实际实现，项目原创支持白话表达；都不反向证明古籍原刊。
5个外部官方URL沿用来源登记记录，本次课程编写未重新外访。每课保留具体待核，
不编书页、不把阴刃逆行第三表或壬科天府说成原刊已核，也不将具名可选法冒充默认。

课程正文与题目是项目原创教学表达，未通过专业人工逐课验收；40题只验证本数据的明确答案与所列依据，
不代表学习者成绩、模型盲评或现实预测有效。倒推时辰继续冻结、隐藏、诚实拒绝。
无需数据库迁移；删除这些新增静态数据与契约即可撤回课程草稿，旧算法不受影响。
