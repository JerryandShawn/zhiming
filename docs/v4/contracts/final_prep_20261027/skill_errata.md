## 原发现与v7处理

**E01：bazi/01_basics.md「适用前提」仍写“靠近交节 ±2 分钟”。** 这是早期口径遗留；当前`adapters/charts/boundary_alerts.py:_jie_alerts`阈值7200秒，即±2小时，见28号M3及`night28-boundary-policy.md`。时辰、23点及午夜边界为900秒，即±15分钟。不能把两种阈值混用。

建议原文替换为：“靠近节令换月边界±2小时，或时辰/子时边界±15分钟，先看实际boundary_alerts及候选；敏感性采样不改变出生事实。” 本轮按v7“只新增”交付此勘误与检测测试，**未修改原章节，也未自动注入chart_skill返回值**。使用时以实际产物和现行契约为准。原章节改字待大脑解除只新增限制；不为此更改算法或v3。

1. `after_successful_chart_compute=true`沿用42号/接线说明D12对chart_skill的统一可见性设计；塔罗与黄历实际输入根另有清楚标注。**不把它认定为计算依赖，不擅自放宽主线工具门**。主线若要分别解锁，另裁定；本线不修改Agent。
2. 紫微、西占、塔罗部分章节“本批U12只有八字”是旧批次说明，不应读成系统永远没有其他规则。建议后续增注：“本章不新建U12条件；当前工具如返回rule_hits，仍只使用实际注册依据，塔罗保留t别名。”本轮留为可读性改进，不伪造新规则。
3. 原刊待核：穷通/滴天髓/渊海具体版本页码、阴刃逆行原典、女命配法、全书异表。已有公开转录定位只能说明当前文字来源；不改成“权威校勘完成”。
4. catalog v2.5与部分章内v2.2/v2.3为目录和正文各自修订时间；本轮未发现必须强制统一的事实依据，不刷版本来掩盖正文未改变。
