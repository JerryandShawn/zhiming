## 1. 设计主张（visual thesis）

**一张安静的宣纸，一位说话有分寸的老朋友。**
- 材质：温暖的宣纸底 + 极淡的纸纹；墨色文字分浓淡三级；朱砂只用来"点睛"（主按钮、当前状态、日主、印章）；古金用于节气、历法这类"时间"信息。
- 气质：克制、留白、像一本排版讲究的书，而不是一个仪表盘。不要星空、不要紫色渐变、不要玻璃拟态、不要霓虹、不要满屏卡片。
- 节奏：大标题少、正文舒展（16px/1.75），信息分组靠留白与细线，不靠框。
- "一页一件事"：每个页面首屏只讲一件主要的事（今日=今天；对话=你们的对话；命盘=你的盘）。

**禁止清单（看到即返工）**
1. 8–12px 的正文或标签（全站最小字号 13px，且仅用于时间戳/注脚类元信息）。
2. 英文装饰小标题（"THE MIRROR"之类）、字间距拉开的"本 命 速 览"式标题。
3. 用 Unicode 符号或 emoji 当图标（◎ ✧ ⭐ ⚠️ 等）。一律用 lucide 图标。
4. 默认卡片堆叠：只有承载交互的容器（提问卡、决策卡、回执、塔罗牌）才用卡片；其余用留白与 1px 细线分组。
5. 每页顶部的大幅装饰标题区。页面标题最多一行 + 可选一行副标题。
6. 假打字光标、无意义的闪烁或呼吸动画。
7. 裸色值、裸字号写在组件里（只能用 token）。
8. 暴露开发术语给用户：`RULE_GAP`、`run`、`ID`、文件名、英文错误码、"Agent"。

## 4. 空间、圆角、阴影、图标

- **间距**（4 的倍数）：`--s-1 4` `--s-2 8` `--s-3 12` `--s-4 16` `--s-5 20` `--s-6 24` `--s-7 32` `--s-8 40` `--s-9 56` `--s-10 72`。
- 页面左右边距：手机 **16px**，平板 24px，桌面内容区 40px。
- 分组：组内 12–16，组间 32–40；分组之间用 `1px --line` 细线或留白，不加框。
- **圆角**：`--r-1 4px`（标签、小按钮）、`--r-2 8px`（按钮、输入框）、`--r-3 12px`（交互卡片、气泡、抽屉顶部）、`--r-pill 999px`（胶囊标签、头像）。新中式偏方正：不要超过 12px 的大圆角。
- **阴影**：只给浮层用一档 `--shadow-float: 0 8px 24px rgba(31,27,22,.10), 0 1px 2px rgba(31,27,22,.06)`（暗色 `0 8px 24px rgba(0,0,0,.45)`）。页面内容不加阴影。
- **描边**：1px；选中/焦点 1.5px `--cinnabar`。
- **图标**：lucide-react，描边 1.5，尺寸 20（默认）/16（行内）/24（底部导航）；颜色继承文字色。常用映射：今日 `sun-medium`、对话 `message-circle`、命盘 `orbit`、塔罗 `layers`、事项 `list-checks`、关于我 `user-round`、设置 `settings-2`、记下了 `bookmark-check`、撤销 `undo-2`、无痕 `eye-off`、飞书来源 `send`、图片 `image-plus`、发送 `arrow-up`、停止 `square`、依据 `book-open`、修订 `pen-line`。
- **印章（品牌标记）**：朱砂方印 SVG，圆角 4px，内含竖排"明镜"二字（serif，`--on-cinnabar`），尺寸 28（导航）/24（对话头像）/40（今日页）。不要用 emoji 或字母头像。

## 8. 文案与语气

- 明镜的声音 = 老朋友：口语、具体、短句。界面标签用动词或名词短语（"记住""撤销""补充出生资料"），不用"请您……"。
- 日期格式：`10月21日（周三）`；时间 `21:05`；相对时间只在 7 天内用（"前天 21:05"），超过用日期。
- 错误文案 = 发生了什么 + 你的内容是否安全 + 你可以做什么。例：
  - 模型不可用："这次没连上明镜的大脑。你的话已经存好了。[再试一次]"
  - 409 冲突："这条在别处刚被改过。你的修改还在，刷新后核对一下。[刷新]"
  - 网络断开："网断了，回答还在继续生成，连上后会自动补上。"
- 计算限制："这一项程序还没有算法支持，下面是一般性的说法，仅供参考。"（替代 `RULE_GAP`）
- 禁用词：应验率、准/不准、注定、必然、化解（销售语境）、Agent、run、ID。
- 空状态示例：对话为空时由明镜主动发第一句（初次相识），不显示空白页；塔罗历史为空："还没有抽过牌。想问点什么？[开始]"。

## 9. 飞书卡片模板（JSON 2.0）

> 以下是结构示意。**实现前必须对照飞书开放平台"卡片 JSON 2.0 结构"与 CardKit 官方文档核实字段名**（尤其 `behaviors`、`streaming_mode`、`element_id`、header `template` 可选值）。卡片配色：header `template` 用飞书预置的红色系（如 `carmine` 或 `red`，以官方可选值为准）表示朱砂；正文 markdown；按钮最多 4 个；正文超过 ~1500 字时折叠"命理依据"为可展开区或改为"在明镜台查看完整内容"链接。

**回答卡（流式）**

```json
  "config": { "streaming_mode": true, "summary": { "content": "明镜正在回复…" } },
  "header": { "title": { "tag": "plain_text", "content": "明镜" }, "template": "carmine" },

```

**提问卡**
```json

  "schema": "2.0",

    { "tag": "button", "text": { "tag": "plain_text", "content": "大概知道" }, "type": "default",
```

## 10. 无障碍与截图验收清单
