# E2：23 号第二节裁定、排除分母与目标年计算

本评测衡量的是与命理比赛标准答案的一致性，不是现实预测的效度；2025 年比赛题可能已进入 2026 年发布模型的训练数据；40 题量级的子集，95% 置信区间约为 ±15 个百分点。

本轮只做载入清点及合成软件试运行。真实模型请求 **0**，新增下载 **0**，专业题库成绩 **null**。
只读已有 `private/e2-sources/` 缓存，不提交题面、选项、答案或出生资料。设计依据是
`23_大脑复核_B1计划与命理线.md` 第二节；旧 v1 的整文件拒绝契约及旧证据保持原样。

## 裁定如何落地

现行入口为 `loaders_v2.load_corpus_v2`、`eligibility_v2`、`protocol_v2`。每题按题面明确
事件目标年判定，不使用出生年或赛季年猜值；赛季年只作 `competition_year=2025` 子集筛选。
自动规则只接受可定位的明确目标子句，区分出生年/明确已知历史年。多个目标年、相对年、
无明确目标年或语义无法定位的题排除，报告保留题目身份哈希、原因与年份片段位置。
不提交任何原文片段。`YearReview` 支持主线逐题本机复核，必须绑定原题评分指纹与真实
`YYYY年` 位置；不能引用题面外年份，不能拿出生年份作事件目标年。

这是**保守自动初筛**，不是对全部真实题完成专业语义审题。非时间题即使本身可作答，因没有
明确目标年也在当前严格年度实验中排除；明确历史年份而没有明确目标问法同样排除，不擅自
认定历史年是目标年。因此本报告的低分母不能冒充官方每年 40 题，也不能与完整子集排行榜
直接比较。若主线在本机确认目标，须用上述有原文定位的复核入口，并重新生成分母。

BaziQA 缺/重复选项标签只排该题，不阻断全文件、不补标签或答案。重复题 ID 的所有副本、
同一案例出生资料冲突也明确排除。筛后 BaziQA 会话只延续实际纳入题，不把排除题正文、
标准答案或补造题插回会话。源题数分布和纳入题数分布都写入报告，不能声称仍为完整五题会话。

## 每题目标年确实进入排盘和缓存

`P8Engine.for_question` 对明确目标年实际调用 P8 隔离排盘。年度采样口径为
`e2-target-year-july01-noon-utc8-annual-view-v1`：该公历年 **07-01 12:00 UTC+8**，
只为读取立春年柱，**不是捏造事件日期**。事件月、日、具体日期均为 `None`；
年初立春前后哪一侧仍未知，不能把中年快照当作整公历年统一事实。

现行年度视图只保留原局与流年；移除快照流月、流日、流时及采样日所在大运，
重建只有 `target.yearly` 的 U2 图并据此重算 U12，避免月日或大运条件残留进命中。
缓存键包含出生资料指纹、目标年与年度方法版本；同生辰不同年份不复用同一时间层。
`MingLi-Bench` / `BaziQA` 来源的 C1–C4 配置拒绝回退到只收生日的固定日期 provider。
C0 仍完全不算盘。旧 v1 `P8Engine.__call__(birth)` 保留原固定目标日和来源 ID 契约。

真实隔离合成负例刻意把旧构造日期设为 `2099-01-01`，同一合成生日分别问 2024、2025：
实际 artifact / profile 日期分别为 `2024-07-01`、`2025-07-01`，流年分别甲辰、乙巳，
profile ID 互异、缓存两项；没有使用构造器的 2099 日期。证据：
`e2-target-year-binding-2026-10-18.json`。

年度裁剪视图派生新的 profile（`actual_method` / 版本带年度采样方法），并根据派生 profile、
目标日期和裁剪后 data 重算 artifact ID 与字典键；没有相同 ID 对应不同内容。
派生方法保留源 profile/artifact 指纹及原局四柱、年度层指纹。测试验证源 bundle 不变、
新 ID 与内容公式一致、原局与年度层保持源值、重新生成的规则命中绑定派生 artifact。

现行安慰剂显式 `year_basis="question_year"`，按来源/题面目标年内做不同命主双射；
无法配对或同一案例跨年无法保持同一供体时拒绝该控制，不跨年补人。
旧 `birth_year` / `competition_year` 仅留历史兼容；脚本中额外 competition 项已标历史 smoke。
题面可能泄漏原生日或原盘，专业题安慰剂仍须本机审题，本次未执行。
