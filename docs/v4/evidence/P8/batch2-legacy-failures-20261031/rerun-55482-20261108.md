# 173 项端口白名单补跑（2026-11-08，命理线，PG 55482）

结论：**仍未验证**。173 项在命理线自己的隔离 PG 上全部停在端口白名单断言，测试主体一项也没有执行，不能算"与基线相同"，这一项没有收口。

## 为什么环境变量覆盖不了
- 白名单写死在测试夹具和发布工具里，没有读取环境变量的入口：例如 `tests/v4/release/test_first_release_acl_pg.py:100`、`tests/v4/release/test_first_release_local_restore_pg.py:128`。
- 发布工具还用服务器真实端口复核：`tools/first_release_local_pg.py:59` 读 `inet_server_port()`，要求它在 {55480, 55481} 里。同类写死的还有 `tools/first_release_acl.py:124`、`tools/first_release_source_pool.py:49`、`tools/first_release_source_profile.py:44` 等。换 DSN 骗不过这一层，只有真正监听 55480/55481 的服务器才能过。
- 要改就得放宽发布工具的安全闸门，这属于主线的发布工具，也违反"不放宽已有断言和安全检查"，命理线没有改。
