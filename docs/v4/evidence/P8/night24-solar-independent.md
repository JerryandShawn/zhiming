# 均时差独立实现核对与交界探针

状态：离线研究；不修改现行NOAA/Meeus方法、v3口径、用户记录或任何界面。最终报告于2026-10-19早间按最终源码重新运行；精确源hash、依赖版本、网格hash及原始42条探针见同名JSON。无模型、网络、数据库写入。

## 方法与原文依据

现行函数为`time_basis_solar.equation_of_time(UTC)`，采用[NOAA计算说明](https://gml.noaa.gov/grad/solcalc/calcdetails.html)的儒略世纪展开式。参考使用Swiss Ephemeris的`time_equ(JD_UT1)`，太阳视赤经与恒星时算法路径不同；这是独立数值实现核对，**不是独立天文观测或出生记录核验**。

[Swiss官方手册](https://www.astro.com/swisseph/swephprg.htm)§18.3.11摘要把输入写作`tjd_et`，与§9.4、已安装pyswisseph说明及[固定v2.10.03 C源码](https://raw.githubusercontent.com/aloistr/swisseph/v2.10.03/sweph.c)不一致。本研究按实际函数要求传UT1，不把`utc_to_jd`返回的TT误作UT；返回单位是日，乘1440转分钟，符号是真太阳时减平太阳时。

参考进程清除`SE_EPHE_PATH`，使用不存在的独立历表目录、Moshier潮汐参数及自动Delta-T。`time_equ`没有历表flags参数或返回值；同历元`calc_ut(SUN, FLG_EQUATORIAL)`得到2052，只是该会话使用Moshier的**伴随调用旁证**，不能说time_equ自报了flags。

Swiss的UT1由Delta-T/闰秒模型推算，未读取IERS实测。1972年前的UTC标签为延伸约定，未来UTC/闰秒亦有模型限制。报告将以下量分列，不把它们混成同一种误差：NOAA与Swiss均时差函数值、Swiss输入UTC标签与推算UT1的微差、推算DUT1，以及在太阳钟坐标中加入DUT1后的差。

## 固定网格

1901–2099年，每年10个固定日期×4个UTC时刻，再加49个闰日×4：共**8156点**。日期固定为1/1、2/11、3/20、4/15、6/21、7/26、9/22、11/3、12/21、12/31；时刻为00、06、12及23:59:59。包含季节与均时差极值附近，仍非逐日或连续覆盖。

运行前固定**5秒研究报警门槛**；超限须保留，不为通过而调整。这不是物理精度、产品验收或交界可靠度保证。

## 交界探针：差异完整保留

六个固定合成边界、经度87.625/104.07/120/121.565/179.9/−179.9，覆盖01:00、23:00及00:00。以NOAA坐标根迭代8次后把物理UTC向下取整秒，再取−30/−5/−1/0/+1/+5/+30秒，共**42次探针，非42个不同边界**。

两套太阳钟坐标均送同一个lunar-python、sect1晚子23点日界和整秒处理。因此这里只核对“不同天文坐标输入是否改变输出”，不属于独立干支引擎验证。

- 日柱或时柱不同：**5/42**；其中日柱不同2次、时柱不同5次，有交集，不能相加成7次。
- ±30秒控制：12次，**0差异**；刻意贴边的5次差异没有删除或改成通过。
- 每条探针保留UTC、两坐标、距名义边界秒数、经度和两套日/时柱，可逐条复核。

现行P8方法没有针对两公式近似差引起的时/日交界变化单独提示。本夜按范围保留现行方法；是否增加主线展示或二次核对列入待决，不自动更换算法。准确记录不等于太阳时近似、经度或历史时标没有误差。
