# P5 敏感提案确认、类别授权与撤销服务

2026-10-23 23:26 +08:00。仅真实本机隔离 PG15.19 与合成原话，模型请求 0、追踪禁用，未改渠道/Agent 循环/提交门，无数据库迁移。

## 行为

消费同一套 P3 pending proposal，保存被确认的原提案内容，不接受替换正文或模型授权旗标。确认必须来自当前用户的非无痕消息，绑定提案 ID/修订及原话范围；拒绝助手消息、问句、拒绝保存、跨 owner、陈旧原话和同一确认消息二次授权其它提案。

“以后这类都记”把类别权限绑到原话与确认消息的可撤销证据。第三人健康同时检查两类权限。后续自动保存保留授权来源；撤销确认会停止已依赖该授权保存的事实、使笔记等派生内容失效、恢复原 pending 提案与两项记忆设置，不覆盖 runtime 等其它设置。授权再次被修改则拒绝覆盖。撤销后新的确认使用新的事实身份，旧事实保持 retired。

拒绝清空 pending proposal 正文，重复请求无新增写入。保存和撤销均沿用 body-free mutation_request。类别 proof 只保留标识/修订/范围，不缓存私人正文。v3 默认授权/第三人确认行为与原事实 ID 路径保留。
