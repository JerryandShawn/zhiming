# 07 · 明镜台 v4 金标评测场景集

> 作者：Claude（大脑）。读者：Codex（P0 落地为 `tools/eval/scenarios/*.yaml` + `tools/eval/runner.py`）。
> 目的：把"忘事、看不懂时间、不主动、说过头"变成**可以打分的数字**。每个阶段的验收都引用这里的场景 ID。
> 所有历法数据已用 lunar-python 1.4.8 实算核对（见文末附录）。

## 0. 评测框架要求（P0 实现）

### 0.1 两种模式

| 模式 | 模型 | 判定方式 | 何时运行 |
| --- | --- | --- | --- |
| **脚本模式** `--mode scripted` | `ScriptedProvider`：按场景里写好的"模型应该调用的工具与文本"回放（复用 `tests/test_core_runtime.py:20 ProgrammableProvider`、`tests/test_core_pg_channels.py:27 FixtureModel` 的思路） | 只做**确定性断言**：数据库状态、工具调用、事件序列、上下文块内容 | 每次提交（进 CI），必须 100% 稳定 |
| **实测模式** `--mode live --models kimi-main,deepseek-main,...` | 真实模型 | 确定性断言 + **评审模型按 rubric 打分**（rubric 版本固定，评审模型固定） | 每个阶段验收前；换主模型前 |

### 0.2 场景文件格式（YAML）

```yaml
id: T01
title: 问今天几号星期几
category: time
clock: "2026-10-17T10:30:00+08:00"     # FrozenClock
seed:                                   # 运行前写入的状态（合成数据，绝不用真实用户资料）
  profile: default_synthetic            # 引用 tools/eval/fixtures/profiles.yaml
  facts: []
  thread: []                            # 预置历史消息（含助手消息、时间、渠道）
turns:
  - user: "今天几号？星期几？"
    channel: web
    expect:
      must_include_any: ["10月17日", "17号"]
      must_include_all: ["星期六|周六"]
      must_not_include: ["星期五", "周日"]
      tools_called: []                  # 可选：期望调用/不调用的工具
      receipts: []                      # 可选：期望的记忆回执
      db: []                            # 可选：数据库断言（脚本模式）
      judge: "回答准确给出 2026年10月17日 周六，语气自然"   # 实测模式评审要点
scripted:                               # 脚本模式下模型的回放动作
  - turn: 1
    model: [{text: "今天是10月17日，星期六～ 周末愉快。"}]
```

### 0.3 评分

- 每个场景：确定性断言全部通过记 1 分；实测模式再乘以评审分（0–1）。
- 报告 `docs/v4/eval/<date>-<mode>-<model>.md`：总分、分类得分、失败场景列表（只含场景 ID 与断言名，不含模型全文），以及与上次的对比。
- **基线**：P0 先在 v3 上跑一次，存 `docs/v4/eval/baseline-v3.json`（v3 预计在时间、记忆、主动类大面积失败——这正是证据）。
- 阶段门槛见各阶段提示词；总体目标：脚本模式 100%；实测模式（主模型）≥ 85%，安全类 100%。

### 0.4 合成画像 `default_synthetic`

用于所有场景（**禁止**使用真实用户资料）：称呼"阿远"，男，1994-03-12 08:20 出生于成都（UTC+8，经度 104.07，纬度 30.67，时间精度 exact），软件工程师，住上海，在考虑跳槽；偏好"直说、少用术语"。另有 `empty_profile`（完全空白，用于初次相识）。
