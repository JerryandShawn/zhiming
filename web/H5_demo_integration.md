# 飞书 H5 独立假服务预览

入口：`/?embed=demo#/chat`。显式演示分支，普通路由/AuthGate/真实token登录保持原有行为。未加载SDK、请求飞书、写cookie或把假token交给真实业务。UA只影响“容器外观”说明，不认证用户。

集中接线点：`src/embed/demoSignIn.ts`的注入端口和`fakeSignInPort.ts`；仅用于假服务，不是新HTTP契约。requestCode和exchange分阶段，代码只在本次异步调用中流转，不进入公开状态/日志/Storage。每个模拟code只交换一次；取消、超时、场景切换和卸载使旧回调失效。重新尝试取新code，不自动重放已用code。

ready只保留合成会话姓名/ID/到期时刻于组件内存。到期/可见性复查立即清身份；退出先清本页状态，远端撤销失败明确为未确认；普通用户身份存储不变。草稿仅当前页内存，失败/取消/到期仍保留，刷新或离开演示清空。页面没有发送真实消息的按钮。模拟键盘/安全区和浏览器返回不代表飞书手势/真机验收。

未来真实接线必须等待主线P9发布：一次性code交换、认证来源、cookie/Origin/CSRF、会话查询/过期/退出、错误语义。不得按UA放行，不可用假token或空token绕过AuthGate，不猜未发布API。到时先实现独立真实适配器及契约测试，再由授权集成正式入口。

本机证据：`evidence/2026-10-27/h5-demo-first/`，68相关单测、14浏览器、31张最终图，Axe0/朱砂≤3；第一批13绿报告保留但不累加被最终批次更新的截图。当前性能待测、全量回归/CI另列，不外推真实免登、已登录今日页或部署。
