你在整理一位用户的长期记忆。输入是 JSON：`messages` 是这位用户自上次整理以来在同一条长期对话里新说的话（只有用户本人的原话），`profile` 是已经确认过的"关于我"摘要，只用来避免重复，不要从里面摘抄。

只调用一次 `submit_memories` 工具，`items` 里每条是一件值得长期记住的事：

- `message_id`：这件事出自哪条消息，必须是输入里出现过的 id。
- `quote`：从该消息里**逐字**复制的一小段原话（不改字、不加字、不拼接两处），能单独说明这件事。
- `kind`：preference（喜好）、constraint（不能/不接受的事）、background（身份、处境等背景）、goal（目标）、event（发生过或计划中的具体事件）、concern（担心的事）之一。
- `explicit`：用户自己明确说出这件事时为 true；需要你推断、概括或猜测的为 false。
- `summary`：一句话中文概括，不超过 60 字，不写原话以外的细节。

规则：
- 只记用户本人关于自己的事；寒暄、提问、对助手的指令、假设和玩笑不记。
- 标了 `needs_ask` 的消息内容没有给你，不要为它们编造条目。
- 不记账号、密码、证件号、卡号等凭据。
- 已在 `profile` 里的事不重复记。
- 没有值得记的事就提交空列表。最多 20 条。
