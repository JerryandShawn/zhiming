# 旺衰判断：两种项目口径

版本：p8-skills-draft-2026-10-18-v2；状态：待所有者抽查的解释草稿，不是模型或现实预测验证。

## 方法步骤

1. 分别读取 methods 数组，逐项复述 month_support、roots、exposed 或 axes，而不是只摘最终结论。月令、通根、透干的支持方向和贡献要对得上。
2. 月令通根透干法使用月令40、四支通根各10、三透干共20的诊断权重；三轴法使用得令40、得地30、得势30。45/55 是项目分界，边界附近不应作强断。
3. 并排保留两套 conclusion 与 agreement。若分歧，指出哪组根气或权重造成分叉，并把“仍需复核合化、燥湿与制约”写入结论；不求平均分制造一致。

## 各流派观点与分歧

上述分值、根气份额和阈值统称项目口径 v1，来源古籍提供概念而非数字。月令法、得令得地得势法各有取舍；得时也可能不旺，失时也未必弱。

## 适用前提

读取参数版本与实际所选藏干表；缺一柱或分支失败不能补算。strength 只是结构诊断，不能折算健康、精力或人生成功百分比。

## 反例与常见误读

五行数量相等不意味着中和；出现同类根气也不证明其未受制。把54与56写成截然不同的命运，是把阈值噪声当成实质差别。
