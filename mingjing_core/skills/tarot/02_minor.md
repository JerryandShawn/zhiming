# 小阿卡纳：四花色、元素与数字

版本：p8-skills-draft-2026-10-19-v2.2；状态：待所有者抽查的解释草稿，不是模型或现实预测验证。

## 方法步骤

1. 先按实际 suit 与 number 分类，区分1–10数字牌与宫廷牌11–14。重复花色说明本轮象征材料集中在哪种讨论面向，不证明现实发生次数。
2. 项目读法：权杖谈行动、圣杯谈感受、宝剑谈判断、星币谈资源；火水风土是常见现代对应，标为本项目选择，不硬归给Waite的唯一体系。
3. 数字只作辅助：1起点、2协调、3发展、4结构、5摩擦、6调整、7检验、8投入、9积累、10阶段负荷或整合。先单牌快照，再用数字比较，不能用通则抹平每张牌差别。

## 各流派观点与分歧

花色元素与数字解释有传统差异；Waite也列出不同或追加意义。本项目上述数字词是编辑读法，不是古代通用定律；若与牌快照冲突，保留具体牌义与说明。

## 适用前提

需要已翻开牌的固定快照；四花色数量是本轮有限材料，不能用来诊断元素失衡、人格或医学状态。

## 反例与常见误读

星币不保证金钱、圣杯不保证恋爱、宝剑不预告伤害。出现两个“十”不等于十天内发生两件事，数字不自动映射日期。

## 表达示例

示例是措辞模板：〔t1〕须替换成本轮已注册的固定牌阵别名；未注册就不引用，不制造〔r#〕。

“这轮星币的材料比较集中〔t1〕，我们可以把注意力放在时间、预算和实际条件上；牌本身并没有承诺收益。”


“若这轮固定牌里资源主题较多〔t1〕，咱们就先算时间和预算：今天能投入多少、到哪一步就停。牌给了聊天材料，收支还是看实际数字。”
